# Gerenciador de Tarefas

Projeto de interface web para um gerenciador de tarefas, desenvolvido com HTML, CSS e JavaScript.

## Visão geral

O projeto contém uma página inicial e uma interface de cadastro e entrada. A navegação e a alternância entre os formulários funcionam no navegador, sem necessidade de instalar dependências.

## Como executar

Abra o arquivo `index.html` em um navegador. Também é possível usar uma extensão como Live Server no Visual Studio Code para servir os arquivos localmente.

## Estrutura do projeto

| Arquivo | Descrição |
| --- | --- |
| `index.html` | Página inicial e navegação principal. |
| `cadastro.html` | Interface de cadastro e entrada. |
| `login.html` | Redireciona para a aba de entrada em `cadastro.html`. |
| `tarefas.html` | Página reservada para a área de tarefas. |
| `style.css` | Estilos das páginas. |
| `script.js` | Alternância entre os formulários de cadastro e entrada. |

## Estado atual

As telas de cadastro e entrada são apenas a interface: ainda não há autenticação, armazenamento de contas ou integração com um servidor. A área de tarefas está em desenvolvimento.
